# Phase 5 decorative asset

`apps/web/public/images/auvylen-synthetic-adults.webp` is an original generated image
created for this project on 2026-10-18 using the available image-generation tool.
It depicts three fictional, clearly adult people in everyday clothing. No private
photographs, datasets, real-person references or third-party stock assets were supplied.
No nationality, ethnicity-based ranking or attractiveness score is attached to a portrait.

The generated 1536×1024 PNG was optimized to a 960×640 WebP (54,550 bytes, quality 76).
Only the WebP is shipped, with explicit Git/Docker exclusion exceptions for its exact path.
Next Image serves this already optimized public asset without runtime optimization or
third-party image requests. The homepage caption identifies it as generated decoration,
not research data. Private images continue to bypass the public image optimizer entirely.

The three `docs/phase5/*-*.webp` browser captures show the public welcome page and
an isolated mocked research workflow with generated one-pixel test images. They
contain no real private data or credentials, are review evidence only, and remain
excluded from Docker build contexts by the existing image rules.
